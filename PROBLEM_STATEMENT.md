# Problem Statement

Healthcare organizations and Medicare stakeholders generate large amounts of provider, healthcare service, utilization and payment data. Raw healthcare data is difficult to interpret and does not immediately reveal which providers have high utilization, which services have high costs, what states have higher healthcare activity, or which factors influence provider utilization.

## Goal

Build an end-to-end analytics and machine-learning solution that transforms raw healthcare provider data into meaningful insights using:

**Python → SQL → Feature Engineering → Machine Learning → Power BI → Tableau**

## Machine-learning problem

Classify providers into:

- Low Utilization
- Medium Utilization
- High Utilization

## Questions to answer

1. Which provider types have the highest service volume?
2. Which states have the highest service utilization?
3. Which healthcare services are most frequently performed?
4. Which providers have the highest service volume?
5. Which provider types have the highest Medicare payments?
6. Which services have high Medicare payment amounts?
7. What is the relationship between services, beneficiaries and Medicare payment?
8. What is the difference between submitted charges and Medicare payments?
9. Which providers/services show high-utilization patterns?
10. Which factors influence utilization?
